- **세 시안이 같은 토큰 이름을 씁니다**(`--c-bg`, `--c-primary`, `--c-w1-ink` …). 시안을 고르거나 섞을 때 컴포넌트는 그대로 두고 값만 바꾸면 됩니다. 글자를 얹는 38개 조합이 세 시안 모두 **WCAG AA 통과(미달 0)**, 글자 조합 최저 A 4.64 · B 4.77 · A×B 4.64:1입니다(§5).
- **브랜드 초록 `#31983d`는 흰 글자 3.69:1, 앱 배경 위 글자 3.39~3.59:1로 미달**(P0-13). 파이뱀과 브랜드 정체성인 초록 색상(hue)은 유지하고 명도만 낮춘 초록을 시안마다 제안합니다. 밝은 초록(`primaryBright`)은 글자를 얹지 않는 장식(캐릭터 몸, 섬 풀밭)에만 씁니다.
- **모션 값은 마스코트 리그의 스프링과 같습니다**(P0-07 `params.ts`의 `SPRING` 4종 + 리그 젤리 3종). UI도 이 7개 스프링만 쓰고, CSS `linear()` easing으로 바꿔 Web Animations·CSS에 그대로 넣습니다(§6).

## 2. 공통 원칙 (어느 시안이든)

### 2.1 색

- 토큰 쓰임은 다섯 가지입니다: **bg**(글자를 얹는 바탕), **text**(글자), **fill**(글자를 얹는 채움 — 버튼·배지), **ui**(경계선·아이콘 3:1), **decor**(장식 전용, 글자 금지). 장식 전용: `line`, `primaryLip`, `primaryBright`, `secondaryLip`, `accent`, `w1`·`w2`·`w3`.
- 글자 조합은 `PAIRS`(§5 표)에 있는 것만 씁니다. 새 조합이 필요하면 `PAIRS`에 추가하고 `npm run contrast -- --check`로 확인합니다.
- 큰 글자 3:1 완화는 쓰지 않습니다. 아이 화면은 버튼 글자도 본문 기준 4.5:1로 맞췄습니다(손글씨 제목은 획이 가늘어 "큰 글자"여도 읽기 어려움).
- 상태색: 성공(초록 계열), 경고(호박색), 오류(벽돌 빨강)는 각각 `*Soft` 바탕 위 4.6:1 이상. 오류는 빨강만으로 전달하지 않고 버그버그 표정·아이콘·문구를 함께 씁니다.

## 4. 시안별 규칙

### 4.1 A 모험 섬

- **분위기**: 모바일 캐주얼 퍼즐·섬 꾸미기 게임의 장난감 같은 분위기(특정 게임을 따라 하지 않음). 비비드 파스텔(민트·코랄·레몬·스카이) + 흰 하이라이트.
- **일러스트 규칙**

| 항목 | 규칙 |
|---|---|
| 외곽선 | 없음. 면과 면은 명도 차이로 나눔(같은 색 계열 진한 아랫면) |
| 하이라이트 | 왼쪽 위 흰 타원 1개(불투명도 0.3~0.45), 큰 면에만 |
| 그림자 | 바닥 접지 타원(남색 16%) + 버튼은 단색 아랫면 6px. 흐림 그림자는 full에서만(P0-16 lite는 단색 오프셋) |
| 질감 | 없음(매끈). 그라디언트는 2단까지. P2-13에서 리그 그라디언트를 단색 + 하이라이트 도형으로 바꿔 렌더 비용을 줄임(P0-07: 캐릭터 1개 CPU 6배 49fps) |
| 형태 언어 | 모서리 반경 큼(카드 24px, 버튼 18~20px), 통통한 비율, 직각 금지 |
| 아이콘 | 보상 아이콘(코인·별·열쇠·하트·보석)은 채움 + 흰 광택, UI 아이콘은 둥근 끝 선 2.2px |

### 4.2 B 마법 그림책

- **분위기**: 수채 그림책·손그림 다이어리. 크림·올리브·테라코타·물빛 블루, 종이 질감, 잉크 갈색 글자.
- **일러스트 규칙**

| 항목 | 규칙 |
|---|---|
| 외곽선 | 잉크 갈색 `#3B2F25`, 2~2.4px, 끝이 둥근 선. 살짝 흔들림(`feDisplacementMap`, 리그는 seed를 8fps로 바꿔 "선 떨림") |
| 하이라이트 | 없음. 대신 수채 물자국(가장자리가 진한 얼룩, `watercolorBlob`)으로 입체감 |
| 그림자 | 흐린 갈색 접지 얼룩 1개. 박스 그림자 대신 종이 겹침(3~4px 어긋난 면) |
| 질감 | 종이 결(입자) + 섬유 얼룩을 바탕 전체에 1겹(`paperGrain`·`paperFiber`). 움직이는 요소 위에는 얹지 않음 |
| 형태 언어 | 살짝 비뚤어진 사각형(±1.5°, 반경 4~10px를 모서리마다 다르게), 찢은 종이 가장자리, 손그림 밑줄 |

- **캐릭터**: 파이뱀은 그림책 주인공처럼 잉크 선으로 그린 선생님(12fps 손그림 리듬). 버그버그는 책 귀퉁이에 낙서처럼 나타나 글자를 갉아먹는 말썽쟁이, 고치면 지우개로 지운 듯 사라지며 웃음. 별똥이는 페이지 사이에서 반짝 떨어지는 별 스티커, 다 모으면 도장 칸이 채워짐.
- **타이포**: 제목 Gaegu 700(×1.15), 본문 Gowun Dodum 400(행간 1.8), 코드 D2Coding(공책 줄 위). 강조는 테라코타 글자 + 겨자 형광펜 밑줄 + 손글씨.

### 4.3 A×B 모험 그림책

- **분위기**: 팝업북·종이 공작 + 캐주얼 게임 지도. A의 섬 지도 구조와 게임 버튼, B의 종이 질감·손그림·손글씨 제목.
- **일러스트 규칙**

| 항목 | 규칙 |
|---|---|
| 외곽선 | 남색 잉크 `#24324A`, 2.6px(B보다 굵고 깨끗하게, 흔들림은 B의 절반) |
| 하이라이트 | A처럼 흰 타원 광택을 외곽선 안에 1개(게임 느낌 유지) |
| 그림자 | 버튼·카드는 단색 아랫면(종이 두께처럼 남색 5~6px), 섬은 종이 접힘 그림자 |
| 질감 | 종이 결은 **바탕에만**, 섬·카드·버튼 면은 매끈한 과슈 |
| 형태 언어 | A의 둥근 형태(반경 16~18px) + 종이 오린 가장자리 |
| 아이콘 | 잉크 선 + 선명한 채움 + 광택 |

- **캐릭터**: 파이뱀은 선명한 초록 + 남색 외곽선, 게임처럼 60fps로 움직이되 젤리는 A보다 덜(`jellyAB` ζ 0.36). 버그버그는 종이를 뚫고 나오는 버그(찢긴 종이 구멍), 보스전은 지도 위 큰 종이 인형. 별똥이는 코인을 스티커처럼 HUD에 착 붙여 줌.
- **타이포**: 제목·버튼 Gaegu 700(×1.15), 본문 Pretendard(1.7). B와 달리 본문에 굵기가 있어 게임 UI(버튼 보조 글자·HUD 라벨)를 쓰기 쉽습니다.
- **시그니처 모션**

| 모션 | full | lite | minimal | 동작 줄이기 |
|---|---|---|---|---|
| 종이 게임 버튼 | 누름 70ms · 복귀 `jellyAB`(k500 c16) | 복귀 `face` 스프링만 | 즉시 | 움직임 0, 색이 진해짐 |

- **월드**: 1장 초록 섬 → 2장 바다·하늘 섬(종이 구름·과슈 바다·팝업 열기구) → 3장 공방 섬(종이 톱니, 노을 과슈). A와 같은 지도에 종이 결·외곽선만 입힌 구조라 A와 에셋을 반쯤 공유할 수 있습니다.

## 8. 디자인 제안 (더 좋은 아이디어)

1. **A×B는 "팝업북 지도"로 정체성을 세우자.** 월드맵을 펼친 책 위의 종이 섬으로 두고, 스테이지를 깨면 다음 섬이 팝업북처럼 일어섭니다(무드보드 "잉크 길 + 팝업 섬"). A의 게임 문법(길·노드·HUD)을 그대로 쓰면서 B의 물성이 "연출"로 살아나 둘을 섞은 이유가 생깁니다. 3D 에셋 없이 `rotateX` 한 축으로 되므로 제작량도 적습니다.
2. **월드 전환 = 책장/바다 넘기기.** B·A×B는 월드 2로 갈 때 "다음 권"을 꺼내는 책 넘김, A는 열기구·배로 바다를 건너는 짧은 이동 컷. 진행 자체가 보상(§6 추가 아이디어)이 됩니다.
3. **버그버그를 오류 메시지의 "목소리"로.** 오류 화면에 빨간 글자 대신 버그버그가 문제 줄을 돋보기로 가리키고 말풍선으로 설명. 고치면 버그버그가 "고쳤다!" 표정으로 바뀌고 체크 배지. 빨강만으로 전달하지 않는 접근성 원칙과도 맞습니다.
4. **보상은 "도장 수첩" 하나로 통일(B·A×B).** 별·코인·업적을 한 수첩에 도장/스티커로 모으면 확률형 없이 수집 욕구를 줍니다(§2.6). A는 같은 구조를 "섬 꾸미기 보관함"으로.
5. **reduced-motion에서도 즐거움을 주는 "정지 컷".** 움직임 대신 만화 효과선·감탄 글자("뽁!", "쾅!")를 정지 그림으로 한 장 보여 줍니다. 움직임 0 원칙을 지키면서 피드백이 밋밋해지지 않습니다.
6. **잉크 번짐은 필터 대신 모양 마스크로.** `feTurbulence` 실시간 필터는 저사양에서 비싸므로(P0-07 B안 필터 비용) 불규칙한 얼룩 SVG를 마스크로 키우는 방식으로 바꿨습니다. 같은 방법을 B의 화면 전환·스테이지 해제에 재사용할 수 있습니다.
7. **코드 크기는 짝수 px로 고정.** 에디터 글자 크기 조절(14~20px)은 2px 단위로만 두면 한글 주석 정렬이 모든 크기에서 맞습니다(§2.2 실측). P2-18 단위 테스트에 15px 같은 홀수가 들어가지 않게 해 주세요.
8. **리그 볼터치 색 보정.** 리그 A의 볼(`#FF8A80`, 불투명도 0.36)이 초록 몸 위에서 갈색으로 섞여 보입니다(무드보드 캐릭터 절). P2-13에서 더 차가운 분홍(예: `#FF7A9A`)과 불투명도 0.5 안팎을 시험해 보세요.
