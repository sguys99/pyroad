# AI 튜터 자유 질문 — 아동 안전 설계 (P9-17)

> 결정: §12-Q58 후속, §12-Q67 ③. 퀘스트 화면 "파이뱀에게 물어보기"의 정해진 질문 버튼 3개(P6-10) 아래에 아이가 직접 쓰는 질문 칸을 둔다.
> 코드: `src/lib/tutor/freeQuestion.ts`(공용 상수·아이용 문구) · `freeQuestionFilter.ts`(서버 전용 거르기) · `prompts.ts`(`FREE_QUESTION_RULES`·`buildFreeQuestionPrompt`) · `src/app/api/tutor/helpers.ts`·`route.ts` · 화면 `src/components/quest/FreeQuestionForm.tsx`

## 1. 흐름

```
아이 입력(100자, 한 줄) ─▶ POST /api/tutor {type: free_question, quest_id, question}
   └ 인증 → 형식(1~100자, 아니면 400) → 한도 tutor:free_question(분 3·하루 20) → 퀘스트·스테이지 잠금
   └ ① 입력 거르기(서버) ── 걸림 ─▶ 200 {blocked, message(아이용 안내)}  LLM 부르지 않음
   └ ② 프롬프트(구분자 격리) → LLM(비스트림)
   └ ③ 답 거르기 ── 걸림·실패 ─▶ 저장된 답변(이번 개념 안내, "저장된 답변" 꼬리표)
   └ 응답 {message, is_fallback, remaining}
```

- 거르기는 **모두 서버**. 화면은 글자 수(100자)와 "이름·연락처·학교는 쓰지 않아요" 안내만 미리 보여 준다(규칙 목록을 내려보내지 않음 — 우회를 가르치지 않게).
- 답은 **흘려 보내지 않는다**(`/api/tutor/stream`은 이 유형을 400). 다 받은 답을 거른 뒤에 한 번에 보여 준다(퀴즈 해설 P7-08과 같은 이유). 그동안 화면은 기존 "생각 중" 말풍선.

## 3. 기록 (내용 없이)

- 로그 `[tutor-abuse]`: 거른 질문은 `free_question_blocked`(info), 버린 답은 `free_answer_blocked`(warning → Sentry). `detail.rule`은 갈래·규칙 id만(`personal:moderation:phone-mobile`, `wellbeing:abuse`). **금칙어 규칙 id(낱말이 들어 있음)는 갈래로 바꿔 남긴다.** 사용자는 해시, 질문·답 원문 없음.
- 분석 이벤트 `tutor_free_question { result: answered | fallback | blocked | answer_blocked }` (서버만, 갈래·규칙도 보내지 않음).
- Sentry: 위 warning 메시지(이유 코드만)와 provider 오류(기존). 질문 원문은 어디에도 넣지 않는다.
- 위험 신호를 운영자나 보호자에게 알리지 않는다(내용을 저장하지 않으므로 누구인지·무슨 말인지 모름) — 아래 남는 위험 ②.

## 4. 남는 위험

1. **필터는 목록 기반이라 새 표현·돌려 말하기는 지나간다.** 특히 위험 신호("다 그만두고 싶어", "집에 가기 무서워")와 이름("나는 민수야")은 오탐 때문에 넓게 잡지 않았다. 이 경우 프롬프트 4번(힘든 일이면 어른 안내)과 답 거르기가 두 번째 방어선. 운영 중 보강은 `freeQuestionFilter.ts` 규칙 + 테스트(걸려야 하는 문장·걸리면 안 되는 문장 함께).
2. **위험 신호를 받은 뒤 사람의 후속 조치가 없다.** 아이에게 어른·1388·112/119 안내만 한다. 보호자 알림·상담 연계는 개인정보·오탐 문제로 이번 범위 밖(필요하면 §12 결정).
3. **모델 답 거르기도 목록 기반**: 개인정보를 묻는 말투("몇 살이에요?")나 미묘하게 부적절한 내용은 못 잡을 수 있다. 정답 비교는 통째로 옮긴 경우만(변수 이름을 바꾼 정답은 프롬프트에 기댐).
4. **프롬프트 주입은 완전히 막을 수 없다.** 입력 패턴 + 격리 규칙 + 출력 검사로 줄일 뿐. 영향은 이 아이 화면의 답 하나(다른 사용자·데이터에 닿지 않음, 도구 호출 없음).
5. **본인 키(Anthropic·OpenAI)** 사용 시 같은 거르기·한도를 쓰지만 그 provider의 데이터 정책을 따른다(질문이 거른 뒤의 글로만 나감).
6. 화면 쪽 대화 기록은 브라우저 메모리에만 있고 저장하지 않는다(새로 고치면 사라짐). 공용 기기에서 같은 화면을 이어 보면 보일 수 있다.
