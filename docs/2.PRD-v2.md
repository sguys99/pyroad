> - 버전: **v2 (제품 v1.0 기준)** · 작성일 2026-11-17 (P12-11)

## 1. 제품 한 줄 · 대상 · 핵심 가치

**pyRoad**는 동물 마스코트 "파이뱀"과 함께 그림책 같은 지도를 따라 퀘스트를 깨며 파이썬을 배우는, 초등학생 전용 웹 서비스입니다. 브라우저만 있으면 설치 없이 진짜 파이썬(Pyodide)을 실행합니다.

| 사용자 | 누구 | 이 서비스에서 하는 일 |
|---|---|---|
| 학생 (주 사용자) | 초등학생. 학년은 1~6학년 중 선택 입력, 내용 수준은 MVP와 같이 텍스트 코딩을 처음 하는 고학년(10~12세) 기준 | 퀘스트 풀기, 보상 모으기, 꾸미기, 작품 만들기·자랑하기 |
| 보호자 | 실제 가입 결정권자. 만 14세 미만이면 법정대리인 | 함께 동의하기, 주간 학습 리포트 보기 |
| 운영자 | 관리자 계정(`app_metadata.role = 'admin'`) | 공지 쓰기, 신고된 글·작품 숨김, 운영 지표 보기 |

핵심 가치
- **게임처럼 재밌게**: 지도·보스·별·코인·꾸미기·자랑하기로 "모으고, 꾸미고, 보여 주고, 다시 오는" 루프 ([계획서 §3](4.upgrade-plan.md)).
- **어디서나**: PC·태블릿은 코드로, 휴대폰은 키보드 없이 푸는 퀴즈로 진도를 나갑니다.
- **6개월 이상의 성장 경로**: 기초 → 응용 → 만들기, 3개 월드.
- **안전하게**: 실명·이메일 비공개, 실제 결제·확률형 뽑기 없음, 서버만 보상을 줌, 과몰입 방지 ([계획서 §2.6](4.upgrade-plan.md)).

## 2. 기능 범위 (v1.0)

### 2.1 처음 만나기: 랜딩 · 로그인

- **랜딩 `/`**: 그림책 지도 히어로, 세계관(월드 3개) 미리보기, 재미 요소 쇼케이스, 캐릭터 소개(파이뱀·버그버그·별똥이), 보호자 안내(안전·AI 원칙·커리큘럼), FAQ. 정적 페이지로 CDN 캐시.
- **로그인 없는 30초 체험**: 랜딩 안에서 `print()` 한 줄을 고쳐 실행. Pyodide를 받지 않는 작은 JS 해석기(eval 없음, §12-Q41). 진짜 파이썬은 로그인 뒤.
- **로그인 3종**: 카카오·네이버·Google (Supabase Auth). 이메일 없이 가입 가능, 계정은 provider identity로 구분하고 이메일로 합치지 않음([계획서 §2.8](4.upgrade-plan.md)). "최근에 ○○로 로그인했어요" 배지, 카카오톡 인앱에서는 카카오 버튼 우선·Google만 외부 브라우저로, 로그인 실패·취소 안내 화면.
- **공용 기기 모드**: 로그인 시트의 "학교·도서관 컴퓨터예요" — 매번 다시 로그인을 묻고, 로그아웃 때 사이트 로그아웃을 안내(§12-Q44).
- **PWA**: 홈 화면 추가(아이콘·manifest). 오프라인 동작은 없음.

### 2.2 온보딩 · 보호자 동의

- 첫 로그인 온보딩: **약속(약관·처리방침 동의) → 나이 확인 → (만 14세 미만) 보호자 동의 → 닉네임 → 파이뱀 색 → 학년(선택) → 등록증 도장**, 이어서 30초 튜토리얼(다시 보기 가능).
- 닉네임 2~10자(완성형 한글·영문·숫자, 금칙어·중복 검사, 추천 닉네임). 공개되는 것은 **닉네임 + 꾸민 파이뱀**뿐([계획서 §2.2](4.upgrade-plan.md) 필드 규칙).
- 나이는 서버가 다시 계산해 `만 14세 미만 / 이상` 결과만 저장. "잘 모르겠어요" = 14세 미만으로 처리.
- **보호자 동의**: v1.0은 "보호자와 함께 이 화면에서 동의"(`guardian_in_person`)만. 보호자 이메일 동의 링크 발송은 v1.1(§12-Q35·Q79).
- **제한 모드**(동의 전 만 14세 미만): 학습은 그대로, 남에게 보이는 쓰기(게시판 글·댓글, 자랑 카드, 갤러리 스티커, 보호자 리포트 만들기)는 막고 금색 안내로 동의를 권함.
- **자동 파기**: 동의가 없는 만 14세 미만 계정, 온보딩·나이 확인을 끝내지 않은 계정은 가입 30일 뒤 매일 크론이 삭제(§12-Q36·Q81, 7일 전부터 화면 안내).

### 2.3 커리큘럼: 3개 월드

월드 → 스테이지 → 퀘스트 계층([계획서 §2.1](4.upgrade-plan.md)). 원본은 `content/worlds/` YAML([content/README.md](../content/README.md)).

| 월드 | 수준 | 스테이지 | 퀘스트 (코드 · 프로젝트 · 퀴즈 · 보스) | 상세 |
|---|---|---|---|---|
| 1 · 파이썬 섬 | 기초: 출력·변수·조건·반복·리스트·함수 | 7 | 72 (43 · 1 · 21 · 7) | MVP 7 스테이지 + 퀴즈·보스 |
| 2 · 코드 바다 | 응용: 문자열·딕셔너리·중첩 반복·random·예외·알고리즘 | 7 | 64 (38 · 2 · 17 · 7) | [curriculum/world2.md](curriculum/world2.md) |
| 3 · 메이커 시티 | 만들기: turtle 그림, `input()` 대화형 프로그램, class 맛보기, 실시간 미니 게임, 자유 작품 | 7 | 50 (22 · 7 · 14 · 7) | [curriculum/world3.md](curriculum/world3.md) |

- 해제: 스테이지는 앞 스테이지의 **보스를 이기면** 열림(§12-Q69). 2·3월드는 이전 월드 클리어 **또는** 그 월드의 실력 확인 퀴즈 합격(첫 스테이지만 열림, §12-Q2).
- 월드마다 지도 테마·랜드마크·BGM이 다르고, 지도에서 스테이지를 골라 퀘스트 목록·별·복습을 봅니다(이어 하기 버튼, 잠금 해제 연출).
- 숫자(퀘스트 수 등)는 2026-11-17 `content/` 기준. 콘텐츠가 바뀌면 이 표보다 `content/`가 맞습니다.

### 2.4 퀘스트 유형 · 채점

| 유형 | 내용 | 기기 |
|---|---|---|
| 코드 | 에디터에 코드를 쓰고 실행 → 출력·코드 규칙으로 채점 | PC·태블릿 (휴대폰은 코드 키보드 툴바) |
| 프로젝트 | 여러 단계로 쌓아 가는 큰 과제. 3월드는 turtle 그림·`input()`·키 입력 게임, 대부분 갤러리 출품 가능 | PC·태블릿 |
| 퀴즈 4종 | 객관식 · 빈칸 채우기 · 순서 맞추기(Parsons) · 버그 찾기. 정답 뒤 "직접 실행해 보기" | 휴대폰 포함 모두 |
| 보스 | 스테이지 마지막 관문. 버그버그 변형 보스와 퀴즈 3~7문제 연속, HP 바·하트 3개, 실패해도 무료 재도전 | 모두 |

- **오늘의 퀴즈** `/daily`: 하루 1~3문제, 복습이 열린 퀴즈를 우선(간격 반복).
- 휴대폰에서는 퀴즈를 추천하지만 코드 퀘스트는 진행 필수로 유지(§12-Q3).
- **채점은 모두 서버**: 정답·힌트·풀이는 학생 브라우저로 내려가지 않고, 완료 API가 서버에서 다시 채점한 뒤 보상 RPC를 부릅니다([계획서 §2.3](4.upgrade-plan.md)). 퀴즈 별·복습 규칙도 §2.3.
- 모든 정답 코드는 CI에서 실제 Pyodide로 실행해 검증합니다([계획서 §2.4](4.upgrade-plan.md)).

### 2.5 코드 실행 · 에디터

- Pyodide(자체 호스팅, 버전 고정)를 Web Worker에서 실행. `input()`, turtle 캔버스 그리기, 키 입력 프레임 루프(`get_key()`), 멈추기·시간 제한을 지원([계획서 §2.9](4.upgrade-plan.md)). `input()`을 못 쓰는 오래된 인앱 브라우저는 "Safari로 열기" 안내.
- 학생 코드는 브라우저 안에서만 돕니다. 보안 경계는 Worker 쪽(`js`·네트워크 차단, CSP `'unsafe-eval'` 없음).
- 에디터: CodeMirror 6 키즈 테마, 글자 크기 조절, 오류 줄 표시, 코드 키보드 툴바. 오류는 빨간 경고 대신 버그버그 등장 + 쉬운 설명(규칙표).

### 2.6 AI 튜터 "파이뱀"

- 퀘스트 화면의 파이뱀 대사창 + "파이뱀에게 물어보기": 정해진 질문 버튼(할 일·개념·왜 이렇게 나왔는지)과 **자유 질문 칸**(금칙어·개인정보 패턴 거르기, 길이·횟수 한도, 범위 밖 질문은 학습으로 돌림). 힌트는 3단계, 오류 때는 자동으로 부르지 않고 버튼으로만(§12-Q56).
- **v1.0 운영은 "저장된 답변"만**(§12-Q80): 서버 AI 키를 넣지 않아 미리 준비한 힌트·설명·답을 보여 줍니다. Gemini 약관이 18세 미만 대상 서비스를 금지해서이며, 학생 본인 Google 키도 받지 않습니다.
- 학생(보호자)이 설정에서 **본인 Anthropic·OpenAI 키**를 등록하면 그 키로 AI 답을 받습니다(서버에 암호화 저장).
- 서버 AI를 Claude로 바꾸는 일은 법률 검토와 함께 v1.1 후보.

### 2.8 상점 · 꾸미기

- 상점 `/shop`: 코스튬(모자·안경·망토·배경)·프로필 프레임·에디터 테마·동행 펫·소모품(황금키·스트릭 방패), 26종. 미리 입어 보기 → 구매 확인 → 연출.
- 꾸민 파이뱀(색 + 코스튬)은 월드맵·대화·축하·HUD 아바타·프로필·공유 카드에 같은 모습으로 나옵니다. 동행 펫은 지도에서 따라다님, 에디터 테마는 공책 에디터에 적용.

### 2.9 자랑하기 · 작품 갤러리

- **자랑 카드**: 레벨업·스테이지 클리어·업적·주간 성장·작품 카드. 카카오톡 공유·이미지 저장·링크 복사. 카드에는 닉네임·파이뱀·성과 숫자만. 공개 페이지 `/share/[cardId]`(비로그인, noindex, "나도 해보기")는 언제든 숨기거나 지울 수 있고 지우면 CDN 사본도 바로 지움.
- **작품 갤러리** `/gallery`: 3월드 작품(코드·썸네일·turtle 그림 기록) 저장은 기본 비공개, 본인이 골라 출품. 친구 작품은 **저장된 그림 기록을 재생**(남의 코드를 실행하지 않음). 반응은 정해진 스티커 5종만(자유 댓글 없음), 신고·운영자 숨김. 학생당 작품 60개(§12-Q76).

### 2.10 보호자 주간 리포트

- 학생이 설정에서 만드는 비밀 링크 `/guardian/<토큰>`(로그인 없이 열람, 언제든 끔). 한 주 학습 요약을 보여 줍니다. 토큰 원문은 저장하지 않음(해시만).

### 2.11 게시판 · 공지

- **게시판** `/board`: 학생 글·댓글. 금칙어·개인정보 패턴 거르기, 길이 제한, 요청 한도, 서로 다른 3명이 신고하면 자동 숨김. 작성자는 닉네임만.
- **공지** `/notice`: 비로그인도 읽음, 관리자만 작성.

### 2.12 프로필 · 설정 · 계정

- 프로필: 레벨·별·업적·통계·학습 달력, 내 자랑 카드·내 작품 관리.
- 설정: 소리(효과음 기본 켜짐·BGM 기본 꺼짐·카테고리별 볼륨), 움직임(연출 단계 자동 또는 직접 선택, 동작 줄이기), AI 튜터 본인 키, 보호자 리포트 링크, 계정 연결.
- 계정: 진행 초기화, 탈퇴(카카오·네이버 연결 해제 포함), 보호자 동의 상태.

### 2.13 운영자

- `/admin` 운영 지표(관리자만, 그 밖에는 404, 읽기 전용): 사용·튜터·퍼널·§1 성공 지표·건강 지표. 정의는 [monitoring.md](monitoring.md).
- 운영 DB 변경은 릴리즈 런북으로 사용자가 적용([release/v1.0-runbook.md](release/v1.0-runbook.md)).

## 4. 범위 밖 · v1.1 후보

v1.0에 넣지 않은 것과 이유는 [계획서 Phase 12 "v1.1 후보"](4.upgrade-plan.md)가 원본입니다. 요약:

- **v1.1 후보**: 보호자 이메일 동의 발송, 서버 AI 튜터 Claude 전환(+ 전송 전 개인정보 가리기), 월드맵 LCP 개선, 퀘스트 라우트 JS 여유 확보, 보안 점검 낮음 항목, 실기기 체크리스트, 시각 회귀·`e2e`를 CI 필수로.
- **v1.0 이후로 미룬 기능**: 주간 리그(opt-in, P9-14 보류), 클래스 모드(선생님·반 코드), 계정 합치기(이메일 없는 계정끼리는 연결 불가).
- **하지 않음**: 실제 결제·확률형 뽑기, 공개 리더보드, 실명·사진 공개, 갤러리 자유 댓글.
- MVP PRD §9의 제외 항목 중 다크 모드·이메일 가입·오프라인 모드·다국어·음성(TTS)도 v1.0에 없습니다.
