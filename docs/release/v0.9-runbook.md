#### 00054 확인 (P11-06)

```sql
select has_table_privilege('anon', 'public.creations', 'SELECT'),
       has_table_privilege('authenticated', 'public.creations', 'SELECT'),
       has_column_privilege('authenticated', 'public.creations', 'visibility', 'INSERT'),
       has_column_privilege('authenticated', 'public.creations', 'hidden_at', 'UPDATE'),
       has_table_privilege('service_role', 'public.creations', 'UPDATE');   -- false | true | false | false | true
select policyname, cmd from pg_policies where tablename = 'creations' order by 1;
-- creations_delete_own DELETE · creations_insert_own INSERT · creations_select_own SELECT · creations_update_own UPDATE

```

배포 뒤(②) 확인: 학생 계정으로 아무 퀘스트에서 `import turtle` 그림 코드(예: 별)를 실행 → 결과 쪽지 아래 "멋진 그림이 나왔어요!" 띠 → "작품으로 저장" → 시트에 그림 미리보기·이름(`title()` 값) → 저장하기 → 띠가 "내 작품함에 저장했어요!" → 프로필 "내 작품함" → 썸네일·이름·자물쇠(나만 보기) → 지우기(확인). `select kind, visibility, octet_length(commands_gz), octet_length(thumbnail) from public.creations;`로 `drawing | private | (100KB 이하) | (200KB 이하)` 확인 뒤 테스트 행은 앱에서 지움. 360px에서도 띠·시트·작품함에 가로 넘침 없음.
