배포 뒤(②) **CDN 사본 지우기(퍼지) 확인** — 앱이 `@vercel/functions` `dangerouslyDeleteByTag('share-card-<id>')`를 부름(Vercel 함수 안에서만 동작, 로컬·테스트는 아무 일도 안 함. 실패해도 사용자 동작은 성공하고 Vercel 로그·Sentry 에 `share-card purge` 로 남음):

- [ ] 카드 하나를 만들고 이미지 주소(`/api/share-cards/<id>/image?v=N`)를 두 번 열어 `x-vercel-cache: HIT` 확인
- [ ] 프로필 → "내 자랑 카드" → 그 카드 "숨기기" → 같은 이미지 주소를 열면 **404**(`x-vercel-cache` 가 HIT 가 아님), 공유 페이지 `/share/<id>`도 404
- [ ] "다시 공개" → 이미지 200(첫 요청은 MISS), "지우기" → 이미지·페이지 404
- [ ] 상점에서 모자를 바꾸거나(또는 닉네임 변경) → 공유 페이지 og:image 의 `?v=` 가 1 늘고, 옛 `?v=` 주소도 다시 그려진 새 그림(옛 사본이 지워짐)
- [ ] 404 가 아니고 HIT 면: Vercel 함수 로그에서 `share-card purge` 오류 확인. 수동으로 지우기: Vercel 대시보드 → 프로젝트 → Caches → 태그 `share-card-<id>` 로 지우기
- 90일 만료 카드는 지울 필요 없음: 이미지 CDN `max-age`가 만료까지 남은 초로 잘려 있어 만료 순간 CDN 사본도 끝남(P9-07). 휴대폰 브라우저에 이미 받은 그림은 최대 1시간 남을 수 있고, 카카오톡으로 이미 보낸 메시지의 미리보기 그림은 지울 수 없음(공유 시트가 보내기 전에 안내)
