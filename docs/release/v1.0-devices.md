# v1.0 실기기 체크리스트 (P12-04 후속)

> - 대상: 크롬북·태블릿·iPad를 직접 들고 확인하는 사람(프로젝트 관리자). **기기 한 대에 10분**이면 끝나도록 줄였습니다
> - 왜: P12-04는 실기기 없이 **헤드리스 값으로 완료 처리**했습니다(사용자 결정 2026-11-16, 계획서 §12-Q78). 아래 항목은 헤드리스로 확인할 수 없어 **미검증**으로 남아 있고, 기기가 생기면 이 표로 채웁니다. 측정·결정: [P12-04-low-end.md](../perf/P12-04-low-end.md)
> - 먼저 해 둘 것: 운영 사이트(`/`)에 **버려도 되는 시험 계정**으로 로그인. 결과에 실명·이메일·계정 이름을 적지 않습니다([v0.4 체크리스트](v0.4-phase3-devices.md) §9와 같은 규칙)
> - 이미 v0.4 체크리스트 §7(사운드 D-71~79)·§8(움직임 D-81~86)을 한 기기라면 그 결과를 그대로 쓰고 여기서는 겹치지 않는 행만 합니다

## 1. 성능 배율 (기기마다 약 5분)

헤드리스 기준값(이 기기의 숫자를 나누면 "이 기기 ≈ 헤드리스 몇 배"가 나옵니다, 측정 2026-11-17):

| 장면 | 헤드리스 CPU 1배 | 4배 | 6배 |
|---|---:|---:|---:|
| 퀘스트 1-1 첫 방문 "코드 돌려보기!" 켜짐 | 1.19초 | 1.54초 | 1.91초 |

헤드리스 값은 같은 컴퓨터의 서버(회선 시간 거의 0)라 실기기 값에는 회선 시간이 더해집니다. 어떤 회선(학교 와이파이·LTE)이었는지 메모에 적어 주세요.

| ID | 절차 | 기대 | 결과 | 메모 |
|---|---|---|---|---|
| R-11 | **시크릿(개인 정보 보호) 창**으로 로그인 → 월드맵 → 아직 안 깬 첫 퀘스트(1-1)를 누르는 순간 스톱워치 시작 → 오른쪽 아래 **"코드 돌려보기!"가 진하게 켜지면** 멈춤 | 숫자(초) 그대로. 3초 안이면 매우 좋음, 6초 넘으면 ❌로 메모 | | |
| R-12 | 같은 퀘스트를 뒤로 갔다가 다시 열기(두 번째 방문) | 2초 안 | | |
| R-13 | 월드맵에서 손가락으로 **위아래 끝까지 2번** 빠르게 쓸기 | 화면이 손가락을 따라오고 멈칫하지 않음. 끊기면 "조금 / 자주" | | |
| R-14 | 아무 퀘스트를 정답으로 끝내 **축하 화면** 보기 (스테이지 마지막 퀘스트면 카드가 여러 장) | 별·코인이 끊기지 않고 올라감, 버튼이 1초 안에 눌림 | | |
| R-15 | 월드맵에 30초 머문 뒤 설정 → 움직임 | "지금 이 기기에서는 '○○'로 보여요"의 이름을 그대로 적기(풍성하게 / 가볍게 / 최소로) | | |
| R-16 | (C만, 선택) Chrome 시크릿 창 → 로그아웃 상태 `/` → DevTools → Lighthouse → 모바일 · Performance | Performance 점수·LCP 적기 | | |
