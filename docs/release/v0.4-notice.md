## 1. 앱 공지사항

### 1-1. 올리는 방법

공지는 앱의 공지사항 화면에서 관리자 계정으로 씁니다(`POST /api/notice`, 서버가 `isAdminUser`로 확인 후 service_role로 기록). SQL로 넣지 않습니다.

1. [ ] 관리자 계정이 `app_metadata.role = 'admin'`인지 확인(v0.4 런북 "관리자 role 설정", B37). 카카오·네이버로 들어오는 관리자는 이메일이 없어 role로만 관리자가 됩니다
2. [ ] 운영 `https://pyroad.vercel.app/notice`(월드맵 오른쪽 위 종 모양 "공지사항" 단추)에 관리자로 로그인한 상태로 들어가 오른쪽 위 **"공지 작성"**
3. [ ] 제목·내용에 아래 §1-2를 붙여 넣고 **"게시하기"** → 목록으로 돌아감
4. [ ] 확인: 로그아웃(또는 개인정보 보호 창)으로 `/notice`를 열어 비로그인에서도 보이는지, 휴대폰 360px에서 목록 카드 제목이 잘리지 않는지, 글을 열어 줄바꿈이 그대로인지
5. 고치기·지우기: 글 화면의 수정·삭제(관리자에게만 보임)

**형식 주의**
- 내용은 **일반 텍스트**입니다(마크다운을 그리지 않고 줄바꿈만 살림, `whitespace-pre-wrap`). `**굵게**`·`#`·링크 문법이 그대로 글자로 보이고 주소도 눌리지 않습니다. 그래서 본문은 "-"와 빈 줄로만 나눕니다
- 제목 100자·내용 5,000자 이내. 목록 카드에는 제목 한 줄(넘치면 잘림)과 내용 **첫 두 줄**만 보이므로 첫 줄에 핵심을 둡니다
- 네이버 검수 전이라 네이버 버튼을 숨기고(`NEXT_PUBLIC_LOGIN_PROVIDERS=kakao,google`) 배포했다면, 본문의 "카카오·네이버·Google"을 "카카오·Google"로 바꾸고 보호자 문단의 네이버 언급을 뺍니다. 검수가 끝나면 수정으로 다시 넣습니다

### 1-2. 공지 문안

**제목**

```text
카카오·네이버 로그인과 "모험가 등록증"이 생겼어요!
```

**내용** (코드 블록 안을 그대로 복사)

```text
안녕, 모험가 친구들! 파이로드가 새로워졌어요.
이제 카카오·네이버·Google 중에서 골라 들어올 수 있어요.

- 처음 들어오면 나만의 "모험가 등록증"을 만들어요.
  별명을 짓고, 내 파이뱀 색을 고르면 금색 도장이 쾅!
- 다른 친구에게는 내 별명과 파이뱀만 보여요.
  진짜 이름과 사진은 보이지 않아요.
- 늘 같은 방법으로 들어와요.
  로그인 화면에서 "최근에 사용" 표시가 붙은 단추를 누르면 돼요.
  다른 방법으로 들어가면 새 계정이 생겨서 내 기록이 안 보여요.
- 전에 놀던 친구도 약속을 한 번 확인하고 별명을 정하면 끝!
  모은 경험치와 기록은 그대로예요.

보호자님께
- 로그인 정보: 카카오·네이버에서는 이용자 식별 번호만 받고 이름·이메일·사진은 받지 않습니다. Google 로그인 이메일은 로그인에만 쓰이며 다른 이용자에게 보이지 않습니다. 다른 이용자에게는 아이가 정한 별명과 파이뱀 그림만 보이며, 예전에 저장된 이름·사진 정보는 지웠습니다.
- 만 14세 미만: 처음 들어올 때 태어난 해를 묻지만 저장하지 않고, 만 14세 미만인지만 기록합니다. 만 14세 미만이면 보호자님이 아이 옆에서 동의 화면을 확인해 주세요(월드맵 위 안내 띠의 "보호자 동의하기" 또는 설정). 동의 전에도 학습은 그대로 할 수 있고 게시판 글·댓글만 쉽니다. 나이를 확인한 날부터 30일 안에 동의가 없으면 계정과 학습 기록이 삭제되며, 7일 전부터 화면에 알려 드립니다.
- 같은 계정 유지: 로그인 방법마다 계정이 따로 만들어집니다. 같은 기기에서는 로그인 화면의 "최근에 사용" 표시를 따라 주세요. 여러 방법을 쓰려면 설정의 "로그인 계정 연결"에서 Google 계정에 카카오·네이버를 연결하면 어느 쪽으로 들어와도 같은 계정입니다. 이미 계정이 둘로 나뉘었다면 아래 메일로 알려 주세요.
- 자세한 내용은 첫 화면 아래와 설정 화면의 "이용약관"·"개인정보처리방침"에 있습니다. 문의: sguys99@gmail.com
```

- 아이 부분은 쉬운 말 11줄(빈 줄 제외), 보호자 부분은 4항목입니다. 문의 메일은 개인정보처리방침에 이미 공개된 운영자 연락처(§12-Q37)입니다
- 숫자·사실 근거: 식별자만(§2.8, P3-01·P3-03), 공개 정보는 별명·파이뱀(P3-13, ③ 00022), 태어난 해 미저장·30일·7일 전 안내(P3-15, §12-Q35·Q36), 연결 방향은 Google에 카카오·네이버(P3-07), 기존 사용자 기록 유지(P3-12)
