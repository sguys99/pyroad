# v0.9 공지 (P11-16)

> - 대상: 공지를 올리는 사람(프로젝트 관리자)
> - 공지는 두 번 올립니다
>   1. **§3 처리방침·약관 개정 안내: 2026-11-24(화)까지** 먼저 게시 — 시행일 2026-12-01(§12-Q76)의 7일 전. [v0.9 런북](v0.9-runbook.md) "처리방침 개정 공지"
>   2. **§2 새 기능 공지: 2026-12-01 이후** 런북 ① 묶음 적용 → ② 병합·배포를 마치고 운영에서 메이커 시티가 열리는 것을 확인한 뒤(런북 ⑤). 태그 `v0.9`(런북 ④)와 순서는 상관없음
> - 날짜는 `src/lib/legal/meta.ts`의 네 값(`TERMS_VERSION`·`PRIVACY_VERSION`·`TERMS_EFFECTIVE_DATE`·`PRIVACY_EFFECTIVE_DATE` = `2026-12-01`)과 같습니다. 공지가 11-24보다 늦어지면 시행일(= 공지일 + 7일 = 배포일)로 네 값과 아래 날짜를 같이 바꾸고 그 뒤에 병합합니다
> - §2에는 날짜를 약속하는 문장이 없습니다(1.0 출시 일정 등)

## 1. 올리는 방법

[v0.4 공지 문서](v0.4-notice.md) §1-1과 같습니다.

1. [ ] 관리자 계정(`app_metadata.role = 'admin'`)으로 운영 `/notice` → 오른쪽 위 **"공지 작성"**
2. [ ] 제목·내용을 붙여 넣고 **"게시하기"**(§3은 11-24까지, §2는 12-01 배포 뒤)
3. [ ] 확인: 로그아웃(개인정보 보호 창)으로 `/notice`가 보이는지, 휴대폰 360px에서 목록 카드 제목이 잘리지 않는지, 글을 열어 줄바꿈이 그대로인지

**형식 주의**: 내용은 일반 텍스트입니다(마크다운을 그리지 않고 줄바꿈만 살림). `**굵게**`·`#`·링크 문법을 쓰지 않고 "-"와 빈 줄로만 나눕니다. 제목 100자·내용 5,000자 이내, 목록 카드에는 제목과 내용 첫 두 줄만 보이므로 첫 줄에 핵심을 둡니다.

## 2. 새 기능 공지 (2026-12-01 병합·배포 뒤)

**제목**

```text
세 번째 그림책 "메이커 시티"와 작품 갤러리가 열렸어요!
```

**내용** (코드 블록 안을 그대로 복사)

```text
코드 바다를 다 모험한 친구들, 이제 진짜로 무언가를 만들 시간이에요!
세 번째 그림책 "메이커 시티"에 일곱 개의 공방이 생겼어요.

- 거북이 화가 공방, 모험 이야기 극장, 두근두근 퀴즈쇼 방송국,
  가상 펫 돌봄 센터, 데이터 탐정 사무소, 미니 게임 오락실,
  그리고 마지막 메이커 박람회까지!
- 거북이에게 명령을 내려 그림을 그려요. 숫자를 누르면 손잡이가 나와서
  밀기만 해도 그림이 바로 바뀌어요.
- input()으로 묻고 답하는 프로그램을 만들어요. 답은 결과 쪽지의 대화창에 써요.
  "시험 손님"이 내 프로그램에 차례로 답해 보고 잘 되는지 알려 줘요.
- 미니 게임 오락실에서는 화살표 키로 움직이는 게임을 만들어요.
  휴대폰과 태블릿에서는 화면의 방향 패드를 누르면 돼요.
- 메이커 박람회에서는 나만의 작품을 기획해서 끝까지 만들어요.
  막히면 "기획 도우미"와 "작품 평가 친구"에게 물어봐요.
- 공방마다 끝에서 버그버그가 기다리고, 마지막에는 "메가 로봇 버그버그"가 있어요.
- 업적 도감에 "메이커 시티" 업적 9개, 상점에 화가 베레모·탐정 모자·
  밤하늘 오락실 공책·거북이 펫 "느릿이"가 새로 생겼어요.

작품 갤러리도 열렸어요!
- 실행 결과 아래 "작품으로 저장"을 누르면 내 작품함에 모여요. 처음에는 나만 볼 수 있어요.
- 메이커 시티 프로젝트를 끝낸 작품은 "작품 보기 → 갤러리에 올리기"로 갤러리에 걸 수 있어요.
  올리기 전에 진짜 이름, 전화번호, 학교 이름이 없는지 같이 확인해요.
- 친구 작품은 메뉴 → "작품 갤러리"에서 구경해요. 거북이 그림은 그리는 모습 그대로 다시 그려지고,
  이야기 작품은 대화가 한 줄씩 다시 나와요.
- 응원은 스티커 다섯 가지(우와·좋아·재밌어·똑똑해·최고야)로만 해요. 글은 남기지 않아요.
- 갤러리에 건 작품은 "자랑 카드"로 만들어 가족에게 보여 줄 수도 있어요.
- 이상한 작품을 보면 "신고"를 눌러 주세요. 어른이 살펴볼게요.
- 내 작품은 언제든 갤러리에서 내리거나 지울 수 있어요.

어떻게 열어요?
- 코드 바다 7단계 "응용 프로젝트 항구"까지 깨면 메이커 시티 첫 공방이 열려요.
- 파이썬을 이미 잘 안다면? 책장의 메이커 시티 책에서 "실력 확인 퀴즈"를 풀어 봐요.

파이썬 섬의 "숫자 맞추기 게임"도 진짜 input()으로 답하는 게임이 됐어요. 다시 해 봐요!

보호자님께
- 메이커 시티는 코드 바다(응용) 다음 과정입니다. 거북이 그림(turtle), 입력을 받는 대화형 프로그램(input), 간단한 클래스, 데이터 정리, 키보드로 움직이는 게임을 배우고 직접 작품을 만듭니다.
- 작품 갤러리는 로그인한 pyRoad 학생에게만 보이고, 작가는 닉네임과 캐릭터로만 표시됩니다.
- 다른 학생의 코드는 실행하지 않고 저장된 그림·대화 기록만 다시 보여 줍니다. 코드는 작가가 "코드도 보여 주기"를 켠 작품만 보입니다.
- 서로 다른 학생 3명이 신고한 작품은 자동으로 숨겨지고 운영자가 확인합니다. 보호자 동의 전(만 14세 미만)에는 구경과 신고만 할 수 있습니다.
- 작품 저장·갤러리로 바뀐 개인정보처리방침·이용약관은 2026년 12월 1일부터 시행 중입니다(11월에 미리 안내). 문의: sguys99@gmail.com
```

- 근거: 공방 이름·최종 보스는 `content/worlds/maker-city/`(P11-12~14), 숫자 손잡이·코드 키보드는 제안 L·M, 시험 손님은 P11-05, 방향 패드는 P11-04, 기획 도우미·작품 평가 친구는 P11-14, 업적 9종·상점 4종은 00057·00058, 갤러리·스티커·신고·자랑 카드는 P11-07·P11-08, 숫자 맞추기는 P11-15, 해제 규칙은 §12-Q2·P10-03(3월드 실력 확인 퀴즈 P11-13)

## 3. 처리방침·약관 개정 안내 (2026-11-24까지 게시)

**제목**

```text
[안내] 개인정보처리방침·이용약관이 2026년 12월 1일부터 바뀌어요 (작품 갤러리)
```

**내용**

```text
작품 저장과 작품 갤러리가 생기면서 개인정보처리방침과 이용약관이 2026년 12월 1일부터 바뀝니다.

무엇이 바뀌나요?
- 새로 저장하는 정보: 학생이 "작품으로 저장"을 누른 작품의 이름, 코드, 거북이 그림의 그리기 명령과 그림 미리보기, 대화 작품의 실행 기록(출력과 입력한 답). 기본은 본인만 볼 수 있습니다.
- 작품 갤러리: 학생이 직접 올린 작품만 로그인한 다른 학생에게 작품 이름·그림(또는 대화 기록)·닉네임·캐릭터·스티커 수와 함께 보입니다. 코드는 작가가 켠 경우만 보입니다.
- 자랑 카드: 학생이 갤러리에 건 작품으로 카드를 만들면, 링크를 받은 사람이 작품 이름·그림(또는 대화 앞 몇 줄)·닉네임·캐릭터를 볼 수 있습니다. 코드는 들어가지 않고, 갤러리에서 내리면 링크도 닫힙니다.
- 반응은 정해진 스티커로만 할 수 있고(자유 댓글 없음), 누른 스티커와 신고 기록(신고한 작품과 사유)을 저장합니다. 누가 눌렀는지·신고했는지는 다른 학생에게 보이지 않습니다.
- 보유 기간: 작품은 학생이 지우거나 탈퇴할 때까지(한 사람 60개), 스티커는 떼거나 작품이 지워지거나 탈퇴할 때까지.
- 이용약관: 게시물에 갤러리 작품을 포함하고, 갤러리 규칙(프로젝트를 마친 작품만, 개인정보 확인, 스티커 반응만, 신고 3명이면 자동 숨김, 운영자 숨김)을 더했습니다.

다시 동의할 필요는 없습니다. 전문은 화면 아래 "개인정보처리방침", "이용약관"에서 볼 수 있습니다.
```
