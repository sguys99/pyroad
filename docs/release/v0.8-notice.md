# v0.8 공지 (P10-12, 초안)

> - 대상: 공지를 올리는 사람(프로젝트 관리자)
> - 언제: [v0.8 런북](v0.8-runbook.md)의 **① 묶음 적용 → ② 병합·배포**를 마치고 운영에서 2월드가 열리는 것을 확인한 뒤(런북 ⑤). 태그 `v0.8`(런북 ④)과 순서는 상관없음
> - 상태: **초안**. 날짜를 약속하는 문장은 넣지 않았습니다(3월드 "메이커 시티"는 "준비 중"이라고만)

## 1. 올리는 방법

[v0.4 공지 문서](v0.4-notice.md) §1-1과 같습니다.

1. [ ] 관리자 계정(`app_metadata.role = 'admin'`)으로 운영 `/notice` → 오른쪽 위 **"공지 작성"**
2. [ ] 아래 §2의 제목·내용을 붙여 넣고 **"게시하기"**
3. [ ] 확인: 로그아웃(개인정보 보호 창)으로 `/notice`가 보이는지, 휴대폰 360px에서 목록 카드 제목이 잘리지 않는지, 글을 열어 줄바꿈이 그대로인지

**형식 주의**: 내용은 일반 텍스트입니다(마크다운을 그리지 않고 줄바꿈만 살림). `**굵게**`·`#`·링크 문법을 쓰지 않고 "-"와 빈 줄로만 나눕니다. 제목 100자·내용 5,000자 이내, 목록 카드에는 제목과 내용 첫 두 줄만 보이므로 첫 줄에 핵심을 둡니다.

## 2. 공지 문안

**제목**

```text
새 그림책 "코드 바다"가 열렸어요!
```

**내용** (코드 블록 안을 그대로 복사)

```text
파이썬 섬을 다 모험한 친구들, 이제 바다로 나갈 시간이에요!
두 번째 그림책 "코드 바다"에 일곱 개의 바다 섬이 생겼어요.

- 산호 문자열 공방, 등대 딕셔너리 도서관, 소용돌이 반복 미로,
  해적선 랜덤 놀이공원, 버그 병원선, 해저 알고리즘 산맥,
  그리고 마지막 응용 프로젝트 항구까지!
- 섬마다 끝에서 버그버그가 기다려요.
  마지막 섬에는 "버그버그 선장"이 있어요. 문제를 풀어 이겨 봐요.
- 응용 프로젝트 항구에서는 용돈 기입장과 단어 퀴즈를 직접 만들어요.
- 섬마다 휴대폰으로도 풀 수 있는 퀴즈가 있어요.
- 업적 도감에 "코드 바다" 업적 7개가 새로 생겼어요. 숨은 업적도 하나 있어요!

어떻게 열어요?
- 파이썬 섬 7단계 "프로젝트 왕국"까지 깨면 코드 바다 첫 섬이 열려요.
- 파이썬을 이미 잘 안다면? 책장의 코드 바다 책에서 "실력 확인 퀴즈"를 풀어 봐요.
  10문제 중 8문제를 맞히면 바로 첫 섬이 열리고 "실력 인정" 배지를 받아요.
  하루에 한 번 도전할 수 있고, 아쉽게 떨어지면 더 연습하면 좋은 단계를 알려 줘요.

파이뱀이 바다에서도 같이 다닐게요. 출발!
```
