## 2. 적용 순서

### 2-1. DB 묶음 ① (병합 전)

- [ ] `release-sql/v1.0-phase12/1_먼저실행.sql` 전체를 SQL Editor에 붙여 실행
- **기대**: Success, NOTICE 세 줄 — `[00059] Google 이름·사진 저장 안 함: 트리거 2개` · `[00060] 크기 CHECK 3개 (모두 VALID)` · `[00061] list_expired_incomplete: service_role 전용, 유예 시작 <지금 시각>`(앞에 `… does not exist, skipping` 안내가 섞여도 정상)
- **다르면**
  - `canceling statement due to lock timeout` → 다른 작업이 표를 잡고 있었던 것. **전체가 되돌려졌으니**(리허설 확인) 1~2분 뒤 다시 붙여 실행. 계속되면 `select pid, state, xact_start, left(query, 80) from pg_stat_activity where datname = 'postgres' and state <> 'idle' order by xact_start;`로 오래된 트랜잭션을 보고 Claude와 상의
  - `permission denied … auth.users`/`auth.identities` (00059 트리거, 개인정보 점검 9절 7) → 전체가 되돌려짐. 앱 배포에는 영향 없으니 멈추고 Claude에게 알림(00059를 뺀 묶음을 만들어 00060·00061만 적용하고 Google 정리는 2-7 SQL을 주기적으로)
  - `[00060] ⚠️ 이미 상한을 넘는 행: 코드 a · 단계 코드 b · provider c → … NOT VALID` → 적용은 성공. 그 행은 **코드를 줄이지 않는 갱신(자동 저장·힌트·다시 풀기)이 거부**되므로(리허설 SIZE-2) 아래로 정리:

```sql
-- 넘는 행 (크기만, 내용은 보지 않음)
select user_id, quest_id, char_length(code_submitted) as code_chars, octet_length(step_submissions::text) as steps_bytes
  from public.user_progress
 where char_length(code_submitted) > 50000 or octet_length(step_submissions::text) > 524288;
select id, char_length(preferred_provider) from public.users where char_length(preferred_provider) > 32;
-- 정리 (5만 자 넘는 코드는 앞 5만 자만, 512KB 넘는 단계 코드 초안은 비움, provider 는 기본값으로) → VALIDATE
begin;
update public.user_progress set code_submitted = left(code_submitted, 50000) where char_length(code_submitted) > 50000;
update public.user_progress set step_submissions = '{}'::jsonb where octet_length(step_submissions::text) > 524288;
update public.users set preferred_provider = default where char_length(preferred_provider) > 32;
alter table public.user_progress validate constraint user_progress_code_submitted_size;
alter table public.user_progress validate constraint user_progress_step_submissions_size;
alter table public.users validate constraint users_preferred_provider_size;
commit;
select conname, convalidated from pg_constraint where conname like '%\_size'
   and conrelid in ('public.user_progress'::regclass, 'public.users'::regclass) order by 1;   -- 3행 모두 true
```
