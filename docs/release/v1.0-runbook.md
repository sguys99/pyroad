### 00060 확인 (B108)

- [ ] 적용 NOTICE가 `[00060] 크기 CHECK 3개 (모두 VALID)`
- [ ] `⚠️ 이미 상한을 넘는 행 …`·`NOT VALID`가 나왔다면 (읽기 전용으로) 행을 확인하고, 학생에게 필요한 코드인지 본 뒤 정리하고 `VALIDATE`:

```sql
-- 넘는 행 (크기만, 내용은 보지 않음)
select user_id, quest_id, char_length(code_submitted) as code_chars, octet_length(step_submissions::text) as steps_bytes
  from public.user_progress
 where char_length(code_submitted) > 50000 or octet_length(step_submissions::text) > 524288;
select id, char_length(preferred_provider) from public.users where char_length(preferred_provider) > 32;
-- 정리 뒤
alter table public.user_progress validate constraint user_progress_code_submitted_size;
alter table public.user_progress validate constraint user_progress_step_submissions_size;
alter table public.users validate constraint users_preferred_provider_size;
```

- 되돌리기: `supabase/rollback/00060_client_write_size_limits.rollback.sql` (제약만 지움, 잃는 데이터 없음)

## AI 튜터: 서버 Gemini 키 빼기 (§12-Q80, B117)

Gemini API 약관(2026-03-23 시행)이 무료·유료 모두 18세 미만 대상 서비스에서 쓰지 못하게 해 v1.0 운영은 **저장된 힌트·답변만** 씁니다(서버 AI 튜터는 v1.1에서 Claude 전환 + 법률 검토). 처리방침 v`2026-11-17`의 "Google로 이전하지 않음"과 맞추려면 **배포와 같은 날** 합니다.

1. [ ] Vercel → Project → Settings → Environment Variables에서 `GEMINI_API_KEY`를 **Production·Preview 모두 삭제**(`GEMINI_MODEL`이 있으면 같이). Development에 있어도 운영과 무관
2. [ ] 재배포(환경 변수는 새 배포부터 적용): Deployments → 최신 Production → Redeploy (v1.0 배포 자체가 이 뒤면 그 배포로 갈음)
3. [ ] **스모크**(학생 계정, 본인 API 키 없음):
   - 퀘스트 1-1 → "파이뱀에게 물어보기" → 힌트 버튼: 답 말풍선에 "저장된 답변" 꼬리표, 대화 아래 "지금은 파이뱀이 준비해 둔 답으로 도와줘요" 쪽지
   - 같은 화면 자유 질문 칸에 "print가 뭐예요?": "지금은 파이뱀이 그 질문에 바로 답하기 어려워요" + 개념 안내(저장된 답변)
   - `/settings` AI 튜터: Google Gemini 줄이 없고 "지금은 파이뱀이 준비해 둔 힌트와 답으로 도와줘요"
   - Vercel 함수 로그에 `GEMINI_API_KEY 가 없어 … (운영은 의도한 상태 …)` 경고는 정상. `[tutor] Fell back`·Gemini 오류가 없어야 함
4. [ ] (읽기 전용) 예전에 Google 키를 등록한 학생 수 — 튜터는 이 키를 쓰지 않고, 설정 화면에서 지우기만 됨:

```sql
select count(*) from public.user_api_keys where provider = 'gemini';
```
