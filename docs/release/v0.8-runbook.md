## Phase 10 병합 (2월드 코드 바다, 릴리즈 묶음 `v0.8-phase10`)

**바뀌는 것**: 2월드 해제 규칙(§12-Q2 — 1월드 7단계 "프로젝트 왕국"을 클리어하면, 지금처럼 스테이지 순서대로 2월드 첫 스테이지가 열림)과 **실력 확인 퀴즈로 건너뛰기**(P10-03, §12-Q72 ② — 1월드를 이미 아는 학생이 잠긴 코드 바다 책의 "실력 확인 퀴즈"로 10문제 중 8문제 이상 맞히면 2월드 첫 스테이지가 열림. 문제 묶음 2벌을 KST 날마다 번갈아, 하루 1번, 서버 채점, 정답·해설은 보여 주지 않음, XP·코인 없음). Phase 10의 다른 작업이 끝나면 이 절에 덧붙입니다.

#### 00052 확인 (P10-03)

```sql
select has_function_privilege('authenticated', 'public.skill_check_start(uuid, uuid)', 'EXECUTE'),
       has_function_privilege('authenticated', 'public.skill_check_submit(uuid, uuid, jsonb)', 'EXECUTE'),
       has_function_privilege('service_role', 'public.skill_check_submit(uuid, uuid, jsonb)', 'EXECUTE'),
       has_table_privilege('authenticated', 'public.skill_check_questions', 'SELECT'),
       has_table_privilege('authenticated', 'public.skill_check_attempts', 'SELECT'),
       has_table_privilege('authenticated', 'public.skill_check_attempts', 'INSERT');   -- false | false | true | false | true | false
select prosrc like '%skill_check_attempts%' from pg_proc where oid = 'public.is_stage_unlocked(uuid, uuid)'::regprocedure;   -- true
```

**콘텐츠 seed (실력 확인 퀴즈 문제)**: ① 묶음 끝에 `supabase/seed.sql`이 들어 있음(00052 뒤 — 문제 테이블이 생긴 다음. 멱등 업서트). 확인:

```sql
select w.slug, c.set_no, count(*), count(*) filter (where c.quiz ? 'accepted')
  from public.skill_check_questions c join public.worlds w on w.id = c.world_id group by 1, 2 order by 1, 2;
-- code-sea 1 10 0 · code-sea 2 10 0 (공개 모양에 정답 없음)
select count(*) from public.skill_check_questions c join public.quests q on q.id = c.review_quest_id
  join public.stages s on s.id = q.stage_id join public.worlds w on w.id = s.world_id where w.slug = 'python-island';   -- 20 (복습 퀘스트는 모두 1월드)
```

배포 뒤(②) 확인: 1월드를 다 깨지 않은 계정으로 책장(`/worlds`) → 잠긴 "코드 바다" 책에 "실력 확인 퀴즈" 쪽지 → 퀴즈 화면 → 시작하기 → 10문제(답을 고른 문제만 진행 점이 채워지고 맞았는지는 안 보임) → 채점하기. 불합격이면 점수와 "더 연습하면 좋은 단계"(정답·해설 없음)만, 책장 쪽지는 "오늘은 이미 도전했어요". 합격하면 컨페티 → "코드 바다 지도 펼치기" → 지도에서 첫 스테이지 잠금 해제 연출. XP·코인은 그대로. `select count(*) from public.coin_balance_mismatches();` 0. **1월드를 이미 다 깬 학생**: 지금처럼 2월드가 열려 있고 쪽지는 보이지 않음(해제 규칙은 그대로).

되돌리기(00052): `supabase/rollback/00052_skill_check.rollback.sql`(먼저 P10-03 이전 앱으로. 실력 확인 퀴즈 문제와 도전·합격 기록을 잃음 — 합격으로만 2월드를 연 학생은 다시 잠기지만, 2월드에서 이미 완료한 퀘스트가 있으면 00046 규칙으로 그 스테이지까지는 열려 있음).
