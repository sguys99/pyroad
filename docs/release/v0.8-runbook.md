## Phase 10 병합 (2월드 코드 바다, 릴리즈 묶음 `v0.8-phase10`)

**바뀌는 것**: **2월드 "코드 바다" 콘텐츠**(P10-04~07 — 스테이지 7 · 코드 퀘스트 38 · 응용 프로젝트 2 · 보너스 퀴즈 17 · 보스 7(문제 42), 바다 해도 지도·랜드마크·보스 외형 7종·BGM `world2`. 지금 운영 책장에서 "준비 중"인 코드 바다 책이 "잠겨 있어요"로 바뀜), 2월드 수준 튜터 설명·용어집(P10-08, 앱만), 채점 공백 정규화·예시 견줘 보기(P10-09, 앱만), 2월드 해제 규칙(§12-Q2 — 1월드 7단계 "프로젝트 왕국"을 클리어하면, 지금처럼 스테이지 순서대로 2월드 첫 스테이지가 열림)과 **실력 확인 퀴즈로 건너뛰기**(P10-03, §12-Q72 ② — 1월드를 이미 아는 학생이 잠긴 코드 바다 책의 "실력 확인 퀴즈"로 10문제 중 8문제 이상 맞히면 2월드 첫 스테이지가 열림. 문제 묶음 2벌을 KST 날마다 번갈아, 하루 1번, 서버 채점, 정답·해설은 보여 주지 않음, XP·코인 없음). **2월드 업적 7종**(P10-11 — 업적 도감에 "코드 바다" 절: 합격 배지 "실력 인정"(코인 없음)·첫 항해·바다 보스 첫 승리·버그 병원선 명의·코드 바다 선장·일곱 바다의 용사·숨김 완벽한 바다, 코인은 기존 티어 금액). 1월드 콘텐츠·학생 진행은 바뀌지 않음.

```sql

       count(*) filter (where q.quest_type = 'code')    as code,
```
