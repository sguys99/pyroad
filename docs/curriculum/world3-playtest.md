## 2. 모의 학생 3명

| | A "느린 3학년" | B "보통 5학년" | C "빠른 6학년" |
|---|---|---|---|
| 배경 | 1·2월드를 천천히 다 깸. 힌트를 자주 엶 | 1·2월드를 보통 속도로 깸 | 2월드를 실력 확인 퀴즈로 건너뛰고 들어옴 |

| 흔한 실수 | 들여쓰기, `self` 빠뜨림, `int()` 빠뜨림, 두 갈래를 둘 다 출력, 고정 값 박기, 함수 만들고 안 부름 | 경계(`<=`/`<`), 위치(섞기·출력을 반복 밖에), 소문자 키 이름 | 더 짧은 다른 방법(`fd`/`lt`, `colors * 4`, `max(key=)`, `isdigit`, `random.sample`, `while 조건`) |

### 페르소나별 요약

- **A (3학년)**: 3-1·3-2는 힌트 2~3단계로 끝까지 갑니다(그림이 바로 보여 동기가 큼). 가장 오래 막히는 곳은 **3-4 펫 설계도**(`self` 빠뜨림 → 영어 `AttributeError`)와 **3-4·3-6 프로젝트**(70분 안팎). 예전 채점에서 A는 **3-3 #1을 "딩동댕·땡 둘 다 출력"으로 통과**했고, **3-6 프로젝트 끝 점수를 0으로 박아도 통과**, **3-F 크레딧을 함수 없이 print해도 통과**했습니다 → 모두 고침(§4). 꽃밭(3-1 프로젝트 4단계)을 한 자리에 다섯 번 그리고 통과하던 것도 고침.
- **B (5학년)**: 전체로 "적당". 억울했던 곳 2곳: **3-4 #2**는 `if 배고픔 < 0: 배고픔 = 0`으로 맞게 막았는데 `max(` 검사로 떨어짐, **3-4 프로젝트 3단계**는 `while choice != "0":`으로 맞게 끝냈는데 `break` 검사로 떨어짐 → 둘 다 통과하게 고침. 느슨했던 곳 2곳: **3-6 #5 `<= 20`**(미션은 "20보다 작으면"), **3-3 프로젝트 섞기를 반복 뒤에** → 둘 다 떨어지게 고침. 소문자 `"right"`는 손님 카드가 "위치가 달라요"로 바로 알려 줌.
- **C (6학년, 건너뛰기)**: 대부분 "쉬움". `fd`/`lt`, `360 // n`, `max(count, key=count.get)`, `random.sample`, `while 조건`, `print(…, score)` 모두 통과. 떨어지는 다른 방법 2개는 **배울 것이 그 문법이라 의도**: 3-1 #6 `for c in colors * 4`(나머지 `%`를 배우는 퀘스트), 3-3 #4 `text.isdigit()`(`try`/`except`를 배우는 퀘스트). 결과 쪽지는 출력이 맞는데 떨어지면 "쓴 방법" 쪽 안내만 보여 줘서 C는 조금 헷갈릴 수 있습니다(2월드 R2와 같음).
